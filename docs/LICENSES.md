## Fonts/icons

No third-party fonts or icons are bundled. Streamlit and Plotly assets are
served by those packages under their own licenses.

## Security

No credentials, tokens, API keys or private keys are stored in the repository.
The API accepts only local STEP uploads with a size cap and writes them under
UUID names in a configured data directory.
