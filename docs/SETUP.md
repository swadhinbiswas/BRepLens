## 2. Development install (CPU + CUDA training)

```bash
cd BRepLens
uv venv --python 3.11 .venv
source .venv/bin/activate
uv pip install -e ".[dev,ml,service,app]"
# CUDA build used for training (driver 620.73.04 supports cu128):
uv pip install torch --index-url https://download.pytorch.org/whl/cu128
uv pip install torch-geometric
python - <<'PY'
import torch, OCP, cadquery, torch_geometric
print("torch", torch.__version__, "cuda", torch.cuda.is_available())
print("OCP", OCP.__version__, "cadquery", cadquery.__version__, "PyG", torch_geometric.__version__)
PY
```

Verified output: `torch 2.11.0+cu128 cuda True`, `OCP 7.9.3.1`,
`cadquery 2.8.0`, `PyG 2.8.1`. CadQuery is a **dev-only** dependency (it pulls
VTK); the hosted app uses OCP directly.

Without a GPU, omit the CUDA install and use the PyPI/CPU wheel; all tests and
the Streamlit demo run on CPU (`torch.cuda.is_available()` gates AMP).

## 3. Data

```bash
python scripts/generate_synthetic.py --per-family 150 --workers 16
python scripts/convert_mfcad.py --limit 3000 --workers 16   # needs data/raw/MFCAD
python scripts/export_schema.py
```

`data/` caches are gitignored; `samples/` (10 STEP files) and `models/` are
committed. See `docs/DATASETS.md` for verified sources and licenses.

## 4. Train and evaluate

```bash
python scripts/train_gnn.py --dataset synthetic --epochs 35
python scripts/train_gnn.py --dataset mfcad --epochs 30
python scripts/evaluate_rules.py --split test
python scripts/evaluate_synthetic_three_ways.py
python scripts/evaluate_head_to_head.py
python scripts/evaluate_similarity.py
```

Evaluation, training and benchmark results above carry their own provenance
(command, seed where applicable, versions, host). Test/coverage artifacts are
produced by `scripts/run_quality_gates.py`; Docker results by
`scripts/docker_smoke_test.py`. The README tables are generated by
`python scripts/make_readme_tables.py`.

## 5. Run the service

```bash
# default: SQLite queue, no Redis needed
uvicorn breplens.service.app:app --host 0.0.0.0 --port 8000
python -m breplens.service.worker --recover-stale
# optional Redis/RQ mode
BREPLENS_QUEUE_BACKEND=rq REDIS_URL=redis://localhost:6379/0 ...
```

Environment variables use the `BREPLENS_` prefix (`BREPLENS_MAX_UPLOAD_MB`,
`BREPLENS_DATABASE_URL`, `BREPLENS_MODEL_PATH`, ...). No secrets are stored in
the repository.

## 6. Run the Streamlit demo

```bash
pip install -r requirements.txt    # inference-only, CPU torch
streamlit run streamlit_app.py
```

Hosted deployment steps: `docs/DEPLOY_STREAMLIT.md`.

## 8. Known environment caveats

- `cadquery-ocp` depends on VTK at install time; the runtime never imports it.
- OCP 7.9 removed `TopTools_ListIteratorOfListOfShape`; the adapter iterates the
  list directly.
- PyG wheels are pure-python; no `torch-scatter` build is required.
- Streamlit Community Cloud does not read `.python-version`; select Python 3.12
  (or 3.11) in the deployment dialog. `pyproject.toml` requires `>=3.11,<3.13`.
